# 图片来源与许可说明

正文里的每张图都应当能回答三个问题：它从哪来、什么时候进入本仓库、以什么许可再分发。这份说明记录 `assets/images/` 下图片的来源、本地化时间与许可边界，供引用、二次分发和后续维护时核对。

图片已全部本地化：正文不再通过 `http://` 或 `https://` 远程引用图片，`src` 一律是从当前 Markdown 文件计算的相对路径；本地文件缺失或改名会直接断链，而不是静默回退到外链。

- **许可徽标**：CC BY-NC-SA 4.0 官方徽标取自 `i.creativecommons.org`，只用于许可声明，不进入知识正文。

## 299 张图片总览

`assets/images/upstream-cs-notes/` 共 299 个文件，主体是各篇正文的示意图、流程图、时序图与结构图。

文件沿用上游 URL 的文件名（多为 UUID 或时间戳形式）而不重命名，以避免不同目录下的同名冲突，并让“本地文件 ↔ 原 URL”可以按后缀直接对应。新增与重写正文中的图片按写作规范补写描述性的 `alt`，复杂图另有“图 N：……”图注与来源说明；尚未重写的归档题解只做路径迁移与引用修正，不逐张重写图注。

## 公式图片的处理

上游正文曾用 CodeCogs 的位图公式，包括 TCP 的平滑 RTT、RTO 以及链路层码分复用中的向量 `S`、`T`，去重后为 4 个 GIF。按本库的资产决策，这些公式已改写为可审查的 LaTeX 文本进入正文；GIF 只用于转写后的视觉复核，不作为最终资产提交，仓库不依赖 `latex.codecogs.com` 渲染数学内容。

- 部分图片在上游正文中引自教材、厂商文档或第三方网页，其原始作者与许可**未逐一核实**，当前只能记为“随上游仓库声明、来源未明”。不能把本仓库的整体许可当作这些图片的授权；若再分发，请自行复核原始出处。
- 个人素材（JWT/Session 长截图）由作者本人提供并保留其权利，需要单独授权时应直接联系维护者。
- 发现图片缺失、错配或出处可以补充时，请在仓库提交 Issue 说明页面与文件路径；新增图片必须放在 `assets/images/` 下并在这里登记来源与许可状态。

## 维护约定

1. 新增图片一律本地化，禁止在 Markdown 中使用远程 `img src`、`file://` 或仓库绝对路径。
2. 图片路径按所在 Markdown 文件的目录用 `/` 计算，不使用手写层级；移动文章时同步更新路径。
3. 来源、时间与许可状态发生变化时，先更新本文件，再同步正文中的“来源/改绘自”图注。
