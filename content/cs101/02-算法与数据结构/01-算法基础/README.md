## 使用方式

- 每篇文章的固定结构：动机 → 模型/不变量 → 操作与复杂度 → 选择边界（什么时候用，什么时候别用）→ 例题应用 → 面试考点与追问。
- 完成标准：能复述该篇的核心结论，能说出复杂度结论的前提，能给出至少一个边界反例。
- 学习顺序按阶段推进即可；阶段内允许跳读，但请先满足“前置”列出的依赖。

## 第一阶段：成本与线性结构

- [01 复杂度分析与算法思想](./01-复杂度分析与算法思想.md) — 前置：无｜能力：为一个实现建立成本模型，分清最坏、平均、期望与均摊｜下一篇：02
- [02 数组与字符串](./02-数组与字符串.md) — 前置：01｜能力：在连续存储上运用双指针、滑动窗口、前缀和与原地修改｜下一篇：03
- [03 链表](./03-链表.md) — 前置：01｜能力：用哨兵、快慢指针与反向重连处理链表边界｜下一篇：04
- [04 栈与队列](./04-栈与队列.md) — 前置：01、02｜能力：用栈、队列、单调栈与单调队列维护顺序和极值｜下一篇：05

本阶段完成标准：能为一段代码写出时间/空间成本，能解释 List、Map、Set 与链表的选择依据。

## 前置关系速查

- `01` 是全板块前置。
- `02—05` 之间没有严格先后，但都建立在 `01` 之上。
- `06` 前置 `03`（节点模型）与 `04`（递归与调用栈的直觉）；`07` 前置 `06` 的完全二叉树与数组表示；`08` 前置 `04`（队列）与 `05`（集合）。
- `09` 依赖 `06`、`07`（堆排序）；`10` 建立在 `09` 的有序数据之上；`11` 前置 `03` 与 `09`（归并分治）。
- `12`、`13` 都需要 `11` 的递归建模与“回溯、记忆化与动态规划的边界”一节。
- `15` 前置 `02`（字符串表示）、`05`（哈希）与 `06`（Trie 的树结构）。

## 主线完成标准

四阶段走完后，应能在不查题解的情况下回答：

- 面对一段新实现，能给出时间/空间成本模型，并说清最坏、期望与均摊口径的差别。
- 面对一个容器选择，能比较顺序存储、链式存储、哈希、堆与树的取舍及退化条件。
- 面对一个搜索或最优化问题，能先判断候选集合如何缩小、子问题是否重叠，再选范式。
- 面对一份题解，能定位它对应本文哪一篇、哪一节，并指出它利用了哪条不变量。
