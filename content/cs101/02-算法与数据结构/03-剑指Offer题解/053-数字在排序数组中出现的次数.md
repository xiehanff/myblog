# 53. 数字在排序数组中出现的次数

## 题目描述

```html
Input:
nums = 1, 2, 3, 3, 3, 3, 4, 6
K = 3

Output:
4
```

## 解题思路

只要能找出给定的数字 k 在有序数组第一个位置和最后一个位置，就能知道该数字出现的次数。

先考虑如何实现寻找数字在有序数组的第一个位置。正常的二分查找如下，在查找到给定元素 k 之后，立即返回当前索引下标。

```java
public int binarySearch(int[] nums, int K) {
    int l = 0, h = nums.length - 1;
    while (l <= h) {
        int m = l + (h - l) / 2;
        if (nums[m] == K) {
            return m;
        } else if (nums[m] > K) {
            h = m - 1;
        } else {
            l = m + 1;
        }
    }
    return -1;
}
```

但是在查找第一个位置时，找到元素之后应该继续往前找。也就是当 nums[m]\>=k 时，在左区间继续查找，左区间应该包含 m 位置。

```java
private int binarySearch(int[] nums, int K) {
    int l = 0, h = nums.length;
    while (l < h) {
        int m = l + (h - l) / 2;
        if (nums[m] >= K)
            h = m;
        else
            l = m + 1;
    }
    return l;
}
```

查找最后一个位置可以转换成寻找第一个大于 k 的位置，避免 k 为 `Integer.MAX_VALUE` 时 `k + 1` 溢出。

```java
public int GetNumberOfK(int[] nums, int K) {
    if (nums == null || nums.length == 0)
        return 0;
    int first = lowerBound(nums, K);
    int afterLast = upperBound(nums, K);
    return afterLast - first;
}

private int lowerBound(int[] nums, int target) {
    int l = 0, h = nums.length;
    while (l < h) {
        int m = l + (h - l) / 2;
        if (nums[m] >= target)
            h = m;
        else
            l = m + 1;
    }
    return l;
}

private int upperBound(int[] nums, int target) {
    int l = 0, h = nums.length;
    while (l < h) {
        int m = l + (h - l) / 2;
        if (nums[m] > target)
            h = m;
        else
            l = m + 1;
    }
    return l;
}
```

需要注意以上两个边界查找方法的 h 初始值为 nums.length，而不是 nums.length - 1。这样当目标值大于数组中所有元素时，方法可以返回数组末尾的插入位置。先看以下示例：

```
nums = [2,2], k = 2
```

如果 h 的取值为 nums.length - 1，边界查找就无法返回 nums.length；而对于 [2,2] 查找 3，我们需要返回数组最后一个位置再往后一个位置，即 nums.length。
